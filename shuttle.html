If you DO find NASA Space Shuttle information or a web page that you want to keep I STRONGLY suggest you download it when you find it. While updating my main page I clicked on the links from many years ago and those sites are gone. An example is the reference to the External Tank, now only to be found on the Wayback Machine on Archive.Org, i.e. External Tank (minus any graphics on the page). Another example is the Columbia STS-107 nsts08399 FMEA CIL, those files were originally hosted at www.jsc.nasa.gov/news/columbia/nsts08399/, that URL is gone now, nor on the Wayback Machine. NASA is slowly closing all the web sites that they had documenting the Space Shuttle. This is the same pattern we saw with Apollo - the F-1 engine that powered the Saturn V isn't really "lost", the blueprints still exist, but the manufacturing knowledge largely is. The people who knew how it actually got built retired or died, and the production tooling was scrapped decades ago. Documents survive; the people who can read them don't. Whether through bureaucratic mismanagement, server consolidation, retirements, or cost savings, the same thing is happening right now to the public-facing Shuttle documentation NASA put online in the 90s and 2000s. Save your own copies. Don't assume they'll still be there tomorrow.

An explanation of the audio tapes. These are tapes of working the OMI (Orbiter Maintenance Instructions) procedure. Some of these procedures:
     - OMI S0007 - Integrated OMI for load and launch of the space shuttle. This consisted of 5 volumes (see below Launch OMI - S0007VL1.TXT thru Launch OMI - S0007VL5.TXT
     - OMI S0017 - Integrated OMI for the TCDT - Terminal CountDown Test. A simulation of launch countdown for the crew of the space shuttle to experience what would happen on launch day and familiarize themselves with the Shuttle they would fly in.
     - OMI V1009.04 - MPS LO2 leak checks, checking the Main Propulsion System for any leaks using a helium leak detector. For a description of the MPS system see Lessons Learned from the Design Certification Operation of the Space Shuttle Integrated Main Propulsion System 20110013223
     - OMI V1011.06 - SSME Leak checks and Flight Readiness Test (Gimbal checks and flow checks). For a full description of SSME procesing see NASA TP - 1998 - 208530 Reusable Rocket Engine Operability Modeling and Analysis Christenson_and_Komar
     - OMI V1202 - Integrated MPS /SSME leak check, checking the Main Propulsion System and the Space Shuttle Maine Engines as a single unit for any leaks using a helium leak detector. For a description of the Helium Signature test see V1202 1030718main_AIAA_HeSigTest and V1202_1030721main_Evolution of the Main Propulsion Helium Signature Test. A 'lessons learned' page is at llis.nasa.gov discussiong rocket system integrated leak checks
